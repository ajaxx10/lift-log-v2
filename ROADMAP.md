# Product roadmap

## v2.0 — Structured project and program workflow
- Modular source files
- Versioned storage schema
- 24-week bench program
- Today dashboard and prescribed workout loading

## v2.1 — Smarter progression
- RIR/RPE tracking
- Adjust next prescribed load after missed or easy sets
- Exercise-specific rest timers
- Plate calculator

## v2.2 — Better planning
- Custom program builder
- Workout templates
- Calendar and skipped-session rescheduling
- Body-weight tracking

## v3.0 — Optional sync
- Optional private account
- Encrypted cloud backup and cross-device sync
- No change to local-first usage for users who prefer no account
